## 构建与查看

```sh
python3 build.py --redesign-only
python3 -m http.server 8000 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8000/redesign/index.html`。连同 redesign/、assets/people/ 分发，不能只复制一个 HTML。不需要前端框架或新增依赖。不要编辑生成页；不要运行默认全量构建覆盖历史页面。

公共头尾由首页模板提取；其余九页正文来自 src/redesign/。公共视觉为 redesign.css，公共交互为 site-shell.js；产品、说明、体验分别使用 catalog、info-pages、experience 资源组，完整团队页使用独立 team-page.css / team-page.js。catalog-data.js 提供共享场景与岗位数据。

## 统一积分口径

- **积分**为用量单位；**剩余积分**为当前可用数量；**预留积分**为任务占用但未结算部分。
- 剩余积分＝未结算积分总额－预留积分。开始预留不是扣费；结算释放未使用预留。
- 页面统一预计消耗、最高消耗、本次消耗。支付金额独立表达，不与积分混用。
- 初始 100、VOC 30、Shopify 50 仅为本地 UI 参数，不是报价。免费预置案例消耗 0。
- 演示完成结算，停止释放预留；刷新恢复不重复结算，积分不足阻止开始。注册/价格返回原成果，不自动追加积分或重跑。
- 本地会话不保存用户输入或联系方式；关闭会话不保证恢复，真实成果认领与持久留存未接通。
